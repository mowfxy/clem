# Features in detail

A closer look at what Mowr does and where each piece lives in the code. For the short version, see the [README](../README.md).

## Accounts and AI connections

In Settings → Models, the usage display polls every second while the workspace is visible; each connected account's Codex app-server is queried at most once every 10 seconds so polling does not spawn a process per second. The optional account switch uses another connected ChatGPT account before each request when the active account has less than 10% left in its short window or less than 5% left weekly, provided the destination supports the selected model and reasoning level. A running request is not moved mid-response; Long Task checks again at each step and preserves completed outputs. Claude and Grok work the same way: each can have several accounts (each Claude account keeps its own `CLAUDE_CONFIG_DIR`, each Grok account its own `GROK_HOME`), usage is shown per account (Claude's from Claude Code's `rate_limit_event` lines, Grok's from its `_x.ai/billing` handshake), and with switching on a request the plan refuses moves to another connected account of the same service. Grok replies are read from `--output-format streaming-messages-json`, whose result is the final message only; plain `json` joins every internal step's text with no separators.

Claude subscription handoff uses a separately installed official Claude Code native CLI. Settings can open the official installation guide or launch its sign-in flow in a terminal. When signed in with a Claude subscription, Claude model aliases appear in the picker and Long Task can offer a compact account, model and thinking choice when no ChatGPT account has capacity. Anthropic does not expose a documented machine-readable subscription usage percentage through this integration, so Claude limits and reset notifications are not shown as measured values. Live Claude sign-in and inference require verification on a machine with an authorized subscription.

## In the app

- **Notices** above the account button stack newest-first, pause on hover and fan out to show all of them: account switches, usage resets, Claude handoffs, staff announcements and support replies.
- **Help & support** (Settings) lists your requests with replies from the team; reply in place.
- **Built-in skills** (`core/mowr-skills.ts`, `core/skills.ts`): every request carries a short index of Mowr's features, plus detailed playbooks for the ones it needs (finding and playing videos, Drive, making and revising PDFs, visuals, web search, files, study sets, checks, exports) and for the kind of work (reports, tutoring, worked solutions…). Models never have to guess how Mowr works.
- **Each AI works as its own CLI** (`desktop/ai-workspace.ts`): Claude Code, Codex and Grok answer in a working folder of the person's files: one per subject or project (`Files/` in the person's Mowr folders), or per chat (`Attachments/`), plus `_text/` (every document's text page by page, OCR included, so a long PDF is read from its text and only the pages whose drawings matter are opened), and per-chat lanes in `Drafts/` and `Outputs/` (any file written there is delivered with the answer). Only changed files are copied before each answer, and this answer's sources are named in the message.
  - Claude Code keeps its own system prompt and file tools (Mowr's rules are appended) under `--restricted`: no shell or code, no computer use or browser, file tools confined to the folder, linked PC folders read-only. Two or more documents go to `mowr-writer` subagents (`--agents`), each reading only its own sources, side by side.
  - Codex keeps its own instructions and gets its shell, sandboxed with `windows.sandbox="unelevated"` (the default elevated sandbox needs administrator setup and refused even to read a file): writes only in the folder, temp excluded, no network. That sandbox cannot confine reads.
  - Grok gets `read_file,list_dir,grep,search_replace,write,web_search,todo_write` with `dontAsk` and `--allow Edit(./**)`, so it writes only in its folder. One unknown name in `--tools` makes Grok load every tool, the terminal included.
  - Kinetra stays the tool for calculations, figures, crops, PDF edits and Office files. Documents are written once as Markdown and typeset with one short call (`"markdown":"Drafts/…/x.md"`, `desktop/markdown-source.ts`); a change is a small edit to that file, which is kept with the document and restored if it goes missing.
- **Web search**: Codex models search the web live on the person's own plan (`web_search = "live"`), Claude uses its WebSearch tool; the chat shows what it is searching. Recommended YouTube videos are found this way and play inline.
- **Chats run side by side**: each chat answers independently on the shared Codex connection; stopping one never stops another. The sidebar shows a spinner on chats that are working and a dot on replies that finished in the background.
- **Visuals for anything**: type `/visual` and any topic, or ask in plain words. Eight built-in physics models answer instantly; anything else is described by the connected model in a small JSON language (`core/visual-spec.ts`) — plots with sliders and animation, step-through diagrams, and charts — which Mowr validates, compiles with a safe expression evaluator (`core/expr.ts`, no `eval`) and draws with the same pen. PNG/SVG/PDF export.
- **Checked numbers**: answers with calculations end with a `check` block; Mowr recomputes each stated formula and flags any value that differs. It confirms arithmetic, not the choice of formula.
- **Second opinion** and **Check sources** under each answer: another connected model (another provider first) reviews the answer; the source check lists which claims your attached files support. Citations written as `[[file, p. N]]` become chips that open the file at that page.
- **Subjects and projects are pages** (`src/space/SpacePage.tsx`): a subject has Overview (today's review, exam countdown, mastery, streak, one-click flashcards, quiz, worksheet or summary sheet), Chats, Flashcards, Quizzes, Files and About. Every card is scheduled with FSRS spaced repetition (`core/srs.ts`) and paced to the exam date.
- **Folders inside Mowr**: make folders (and folders inside them) in a space's Files, upload or drop files straight into one, drag files between them or use Move to. A worksheet Mowr makes from a subject lands in its Worksheets folder. Subject ZIPs keep the folders.
- **Real PDF editing** (`src/pdf/`): tell Mowr what to change and the same file changes. PDFs Mowr made are re-typeset from their kept source (`spec-<id>`); any other PDF has the changed lines re-set in place with matching font style, size and colours (`core/pdf-edit.ts`). Edits are saved into the file at once with changed lines highlighted, Before/After to compare and Undo for earlier versions. Asking the chat to change a document it made (“make it longer”, “the diagram is wrong”) revises that same file through Kinetra's `revise`, never a new one.
- **Screen capture**: **Ctrl Shift Space** from any app (or + → Capture screen) freezes the screen, lets you drag a region and attaches it to the chat for a ChatGPT model.
- **File changes**: with a linked folder, models propose edits as diffs. Nothing is written until you apply; every change can be undone from the chat or Settings → Linked folders, and undo refuses to overwrite newer work.
- **Folders on this PC**: the Files page lists linked folders; **Browse** reads any text or code file inside Mowr, and “Tell Mowr what to change” sends the request to the folder’s chat, project or subject, where it comes back as a diff to apply.
- **Folder watching** (`desktop/folder-watch.ts`): a file changed outside Mowr in a linked folder raises a notice that prepares a flashcard update (subjects) or a summary of the changes. Mowr’s own applied edits are absorbed silently. Settings → Linked folders turns it off.
- **Search everything**: **Ctrl Shift F** (or Ctrl K → Search everything) searches chats, uploaded file contents, linked folders, flashcards and spaces on this PC with one ranking (`core/search.ts`).
- **Sharing**: **Share** on a subject (or Share folder) picks sensible contents, saves a `.mowrpack` to Downloads\Mowr and lets you drag it straight into WhatsApp, Discord, Teams or an email. Packs carry flashcards, quizzes and chosen folders — never chats, memory or review history (`core/study-pack.ts`). Dropping a pack on the window, double-clicking it or importing it from Subjects opens a one-click preview.
- **Offline reading**: when Mowr cannot reach the account service, “Open my files offline” opens the local workspace read-only; sending returns when the connection does.
- **Typography** (`src/type.css`): Mowafy Serif is Mowr's voice and what you read (one headline per screen, answers, documents, study cards); Mowafy Sans is names and interface (every sub-heading, dialog title, label and control). Both ship Regular (400) and Bold (700) only, sizes come from one scale, and stylesheets name fonts only through `--sans`, `--serif` and `--mono`.
- **Settings** (`src/settings/`) is a large window over the workspace, like the file viewer: you, a finder and the sections on the left; Profile holds your name, picture and account, Skills lists your ways of working, and Usage shows the last 30 days, tokens and habits worked out from the chats on this PC.
- **Ctrl K** opens the command palette (chats, projects, subjects, settings); **Ctrl N** starts a new chat; **Ctrl ,** opens Settings.
