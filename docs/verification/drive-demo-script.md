# Clem: Google Drive OAuth verification demo, shot script

Scope: `https://www.googleapis.com/auth/drive` (restricted). Final file: `docs/verification/clem-drive-demo.mp4`, English, under 5 minutes, uploaded Unlisted.

Two OAuth clients exist in the Google Cloud project and both consent flows are shown:

| # | Client | Where it starts | Scope shown |
|---|--------|-----------------|-------------|
| 1 | Drive connector (Web application), redirect `https://clem.m4labs.xyz/api/drive/callback` | Clem → Settings → Connectors → Google Drive → Manage → Continue with Google | `https://www.googleapis.com/auth/drive` |
| 2 | Google sign-in (`GOOGLE_AUTH_CLIENT_ID`, through Supabase) | Clem sign-in screen → Sign in with browser → Continue with Google | `openid email profile` |

## Before anything is recorded

### Checked before recording (these are on screen, and Google reviewers read them)
1. Done: the Drive connect card says Clem reads the folders and files you choose to open and saves files you add, and Clem's files, into folders you link ([src/drive/DrivePicker.tsx](../../src/drive/DrivePicker.tsx)), matching the `drive` scope and the video.
2. Done: the privacy policy at https://m4labs.xyz/privacy (source: the m4labs-site repo, `src/legal.mjs`) names the `drive` scope, says when Clem reads and writes Drive, and has the Google API Services User Data Policy / Limited Use statement.

### Screen and browser
- Screen is 2880×1800 at 200%. The recorder captures the top 2880×1620 (16:9). The edit scales it to 1920×1080. Keep everything you want seen in the top 90% of the screen; the taskbar will not be in the video.
- Use Chrome, one window, bookmarks bar hidden, no other tabs, no extensions icons that show a name or email. Close Slack/Discord/notifications (turn on Focus assist).
- Chrome must be signed in to **two Google accounts** so Google shows the account chooser (its URL contains `client_id` and `scope`; the later consent page URL does not). Use your own Google account plus a throwaway.
- Chrome must also be signed in to clem.m4labs.xyz so the Drive connect redirect goes straight through.
- Windows theme/wallpaper: plain. No personal files visible on the desktop or in Explorer.
- Clem maximised.

### Sample files
Run once: `node scripts/verification/make-samples.mjs`. It writes `Desktop\clem-demo-files\` with `physics-notes.pdf`, `past-paper-1.pdf`, `demo-clip.mp4` (20 s test pattern with a tone) and `dropped-file.txt`.

In **drive.google.com**, signed in as the demo account, make this by hand (in the Drive web UI, not through Clem; it matters for the “folder the user created” point):
```
My Drive / Clem Demo - Physics /
    physics-notes.pdf       (upload)
    demo-clip.mp4           (upload)
    Past papers /
        past-paper-1.pdf    (upload)
```
Leave `dropped-file.txt` and the worksheet for the take; they must not be in Drive yet.

In Clem: sign out of the desktop app, and have a subject ready to be created in scene 3 (call it “Physics”). Pick a model that answers quickly.

## How recording works
One file per scene in `docs/verification/takes/` (gitignored). One command per scene; it counts 3-2-1, records, and **press `q` in that terminal to stop**. Re-running a scene keeps the old take as `*.old-<time>.mkv`.

```
node scripts/verification/record.mjs 00-site
node scripts/verification/record.mjs 01-signin
node scripts/verification/record.mjs 02-connect
node scripts/verification/record.mjs 03-link
node scripts/verification/record.mjs 04-read
node scripts/verification/record.mjs 05-drop
node scripts/verification/record.mjs 06-add
node scripts/verification/record.mjs 07-edit
node scripts/verification/record.mjs 07b-manage
node scripts/verification/record.mjs 09-revoke
```
(Raw equivalent: `ffmpeg -f gdigrab -framerate 30 -video_size 2880x1620 -i desktop -c:v libx264 -preset ultrafast -crf 20 -pix_fmt yuv420p takes\<scene>.mkv`.) The title card, the “why drive” card (08) and the end card (10) are generated by the edit; you do not record them.

Tips for every take: start from the screen state listed under “Start with”; move the mouse slowly; pause 2 s on anything that matters; if you fumble, stop and redo the whole scene.

## Scenes

Captions below are burned in by the edit (one per feature, bottom of frame).

### 00 Title card (generated)
“Clem: Google OAuth verification demo / https://www.googleapis.com/auth/drive / https://clem.m4labs.xyz / https://m4labs.xyz/privacy”.

### 00-site  Website and privacy policy (≈20 s)
Start with: Chrome open on a blank tab.
1. Type `clem.m4labs.xyz` in the address bar, Enter. Let the home page load, scroll slowly down and back up.
2. Scroll to the footer, click **Privacy policy** (it opens m4labs.xyz/privacy). Scroll slowly to **Google user data** and pause 4 s on it so the `drive` scope, “Data we access”, “How we use it” and “Limited Use” can be read.
Caption: “Clem is a Windows desktop app. The website clem.m4labs.xyz hosts sign-in and the Drive consent redirect; the privacy policy at m4labs.xyz/privacy is linked from the footer.”

### 01-signin  Client 2: Google sign-in (≈60 s)
Start with: Clem signed out, showing the sign-in screen.
1. Click **Sign in with browser**. Chrome opens clem.m4labs.xyz sign-in.
2. Click **Continue with Google**. The Google account chooser appears.
3. **Address bar hold:** click the address bar (shows the start of the URL with `client_id`), hold 4 s, press **End** (shows the end with the `scope`), hold 4 s. Press Esc.
4. Pick the demo account. On the consent screen pause 3 s so “Clem” and the requested info (name, email, picture) can be read. Click **Continue**.
5. Back in Clem, signed in. Pause 2 s on the home screen.
Caption: “OAuth client 2 of 2: Google sign-in (“Continue with Google”). Clem uses it only to identify the user’s account (email and basic profile).”

### 02-connect  Client 1: Drive connector (≈80 s)
Start with: Clem signed in, Drive not connected.
1. In Clem: avatar/Settings → **Connectors** → Google Drive → **Manage**. The **Connect Google Drive** card shows. Pause 3 s.
2. Click **Continue with Google**. Chrome opens (clem.m4labs.xyz, then Google).
3. **Address bar hold** on the account chooser exactly as in 01: click bar, 4 s, End, 4 s, Esc. Here `client_id` is the Drive client and the scope reads `https%3A%2F%2Fwww.googleapis.com%2Fauth%2Fdrive`.
4. Pick the demo account. On the consent screen pause 4 s: app name **Clem**, the “See, edit, create and delete all of your Google Drive files” line.
5. Click **Continue/Allow**. The page “Drive is connected.” shows; pause 3 s.
6. Click back to Clem; the Drive browser appears listing My Drive. Pause 2 s.
Caption: “OAuth client 1 of 2: the Google Drive connector. It requests one scope: https://www.googleapis.com/auth/drive”

### 03-link  Read: link a Drive folder to a subject (≈45 s)
Start with: Clem, Drive connected, no subject yet.
1. Create a subject named **Physics** (Subjects → New).
2. In the subject open the **Files** tab → **Add** → **Link Google Drive**. The Drive browser opens on **My Drive** (Shared with me is the tab beside it).
3. Open **Clem Demo - Physics**: its files and the **Past papers** subfolder are listed. Open **Past papers** (its file shows), go back with the breadcrumb.
4. Click **Link “Clem Demo - Physics”**.
5. The Files tab shows the Google Drive folder with its files and the “Past papers” folder card; open the subfolder and back. Pause 3 s.
Caption: “READ: the user browses their Drive and links a folder they made to a subject. Its files and subfolders are listed live from Drive; nothing is copied to the PC.”

### 04-read  Read: stream a PDF and a video, ask about a file (≈75 s)
Start with: the Physics subject with the linked folder.
1. Click **physics-notes.pdf**. It opens in the viewer. Scroll one page, pause 2 s, close.
2. Click **demo-clip.mp4**. The video plays inside Clem (streamed from Drive). Play 5 s, seek by clicking the timeline once to show streaming, close.
3. Open the ☰ menu on `physics-notes.pdf` → **Ask about it**. In the chat type: `What force is needed to accelerate the 2 kg trolley at 3 m/s²?` Send. Wait for the answer (6 N) and a link to the Drive file. Pause 3 s.
4. Start a new chat and ask: `Which file in my Drive covers past papers?` Clem searches Drive and answers with a link to `past-paper-1.pdf`. Pause 3 s.
Caption: “READ: PDFs and videos are streamed from Drive when opened. Clem reads a file, or searches Drive, only to answer the user’s question.”

### 05-drop  Write: drag a file from Explorer (≈40 s)
Why drive and not drive.file: the folder was created by you in Drive, not by Clem.
Start with: the Physics subject with the Drive folder visible, and a File Explorer window next to Clem showing `Desktop\clem-demo-files`.
1. Drag **dropped-file.txt** from Explorer onto the Drive folder list in Clem. It appears at once with the turning ring, then a check. Pause 3 s.
2. Open Chrome on **drive.google.com**, open **Clem Demo - Physics**: `dropped-file.txt` is there. Pause 3 s. Show the folder title so it is clear it is the folder you made.
Caption: “WRITE: a file the user drops into the Drive folder they linked is uploaded to that folder, then marked as saved.”

### 06-add  Write: Add files, then save a worksheet into Drive (≈70 s)
Start with: the Physics subject, Files tab.
1. Click **Add files** (Google Drive header), choose `past-paper-1.pdf` from `clem-demo-files`, Open. It appears with ring → check.
2. On the subject Overview click **Worksheet** (“A PDF, saved to Worksheets.”). Ask for a short physics worksheet if prompted and wait for it. It is kept on this PC, under **On this PC** in the Files tab.
3. Open the worksheet’s ☰ menu → **Save copy in Drive**. It appears in the Google Drive folder with ring → check.
4. Switch to drive.google.com and refresh **Clem Demo - Physics**: both files are there. Pause 3 s.
Caption: “WRITE: “Add files” uploads files the user chooses to the linked folder; a worksheet Clem made is saved into it only when the user picks Save copy in Drive.”

### 07-edit  Write: approved edit updates the same Drive file (≈75 s)
Start with: the Physics subject, Files tab showing the worksheet in the Google Drive folder (from scene 6).
1. Open the Drive copy of the worksheet. Click **Ask or edit with Clem**. Type `Add one harder question at the end and leave space for the answer.` Send.
2. The Before/After bar appears. Click **Before**, then **After**; pause 2 s on each.
3. Click **Keep**. The header ring turns, then a check (“In sync with Google Drive”). Click **Done**. Pause 2 s.
4. Switch to drive.google.com, open the folder: the worksheet appears once (not duplicated), open it or hover to show a new “Modified” time. Pause 3 s.
Caption: “WRITE: after the user approves an edit, the same Drive file receives the new version. It is not duplicated.”

### 07b-manage  Write: rename and move to trash, from Clem (≈40 s)
Start with: the Physics subject, Files tab, the Google Drive folder.
1. Click the pencil on `dropped-file.txt`, rename it to `dropped-file-renamed.txt`, Enter.
2. Its ☰ menu → **Move to Drive trash** → confirm **Move to trash** (“…you can restore it for 30 days”). It leaves the list.
3. Switch to drive.google.com: the folder no longer shows it, and Drive’s **Trash** shows `dropped-file-renamed.txt`. Pause 3 s.
Caption: “WRITE: the user can rename a file or move it to Drive’s trash from Clem. Clem never permanently deletes Drive files.”

### 08 Why the full drive scope (generated card)
“Users link folders they made themselves. drive.file shows none of what is already inside such a folder and can’t add files to it, so Clem needs the drive scope to list the linked folder and save into it. Clem reads and changes Drive only when the user acts. Data is read live and streamed, never copied to our servers. Disconnect revokes access.”

### 09-revoke  Disconnect (≈45 s)
Start with: Clem, Settings → Connectors.
1. Google Drive → **Manage** → **Disconnect** → confirm **Disconnect** in the dialog. The Connect card returns. Pause 3 s.
2. Optional: Chrome → `myaccount.google.com/connections` (Your connections to third-party apps and services) and show Clem is not listed.
Caption: “REVOKE: Disconnect in Clem revokes the Google grant, so Clem can no longer read or write the user’s Drive.”

### 10 End card (generated)
Support email `support@m4labs.xyz`, privacy policy https://m4labs.xyz/privacy, the scope.
