# Google verification submission pack

| File | What it is |
|------|-----------|
| `youtube-upload.md` | Exact YouTube steps (Unlisted), title and description to paste |
| `scope-justification.txt` | Text for the verification form's "scope justification" box |
| `../mowr-drive-demo.mp4` | The video, once recorded and built (not committed) |
| `../drive-demo-script.md` | The shot script |

Order: record the scenes (`node scripts/verification/record.mjs <scene>`), build (`node scripts/verification/build-demo.mjs`), check `docs/verification/frames/`, upload, paste the link into the form.
